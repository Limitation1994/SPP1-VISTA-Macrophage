# SPP1-VISTA-Macrophage
Code and analysis scripts supporting the study of SPP1⁺VISTA⁺ macrophage-mediated CD8⁺ T-cell exhaustion and immunotherapy resistance in gastrointestinal malignant ascites.
Data analysis was performed using GraphPad Prism (version 9.0) and R (version 4.2.2). Single-cell RNA sequencing data were processed and analyzed using Seurat (version 4.4.0), Monocle (version 2.3.2), CellChat (version 1.6.1), inferCNV (version 1.20.0), and clusterProfiler (version 4.12.6) in R. Transcription factor regulatory network analysis was conducted using pySCENIC (version 0.11.2) in Python. Image quantification was performed using ImageJ (version 1.53). Flow cytometry data were analyzed using FlowJo (version 10). No custom code central to the conclusions was used beyond standard packages and published pipelines.
